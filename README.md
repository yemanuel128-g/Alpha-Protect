# Alpha Protect

Holding page for alpha-protect.nl while the real site is being built.

One static HTML file. No build step, no dependencies, no framework.

## Files

| File | What it is |
|---|---|
| `index.html` | The entire page, CSS included |
| `logo-cut.png` | The logo with the black background knocked out to transparency |
| `design.md` | Locked colour decisions and the open points on the logo |

## Run it locally

```bash
python -m http.server 4180
Then open http://localhost:4180
```
